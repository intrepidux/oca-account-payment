Edit or replace a posted payment through the standard Register Payment wizard
prefilled with the original payment data.

Two modes are available per company (Accounting settings):

* **Replace** (default): cancel the original payment and create a new one with
  full traceability between both records.
* **Edit**: reset the same payment to draft, adjust it in the wizard, and
  re-post it while keeping the same record.

Upgrading from 15.0.1.x keeps **Replace** as the default behavior.
